# Gita Screensaver

Bhagavad Gita shlokas as an Android screensaver (Daydream) with a simple browse app.

- Status: planning / setup — see `PROGRESS.md`
- Instructions for Claude: see `CLAUDE.md`

## Data source
- Shlokas live in `app/src/main/assets/shlokas.json`.
- Sanskrit (Devanagari) and IAST transliteration: the traditional Bhagavad Gita text, which is public domain. To be cross-checked against the Gita Press edition before release.
- Hindi and English meanings: simple original renderings written for this app, still to be reviewed.
- Currently a sample of 7 shlokas; the full 700 will be added later.
